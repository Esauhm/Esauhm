Backend desarrollado con **ASP.NET Core Web API y .NET 10**, utilizando Clean Architecture.

- API REST versionada mediante `/api/v1`

- SQL Server 2022
- Repository Pattern
- Service Layer

- Health Checks
- OpenAPI / Swagger
